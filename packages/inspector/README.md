### 🛠️ Welcome to unplugin-pwa/inspector

Visual inspector for the PWA generated by `unplugin-pwa`. Explore your resolved configuration, web manifest and service worker details from a clean GUI, without digging through terminal logs or triggering blind builds.

> 💡 **Note:** you normally don't need to install this package directly. It ships the inspector SPA as static files; `@unplugin-pwa/core` only exposes where its `dist` lives, and each integration (e.g. `@unplugin-pwa/vite`) serves it through a dev-server middleware or [DevFrame](https://github.com/devframes/devframe).

### ✨ Key Features

* 📦 **Configuration Explorer:** check exactly how your final PWA configuration has been resolved.
* 📱 **Web Manifest Preview:** inspect metadata, icons and colors as the browser will interpret them.
* ⚙️ **Service Worker Audit:** review caching strategies, precached routes and Workbox integration at a glance.
* 🖼️ **DevFrame Support:** compatible with [DevFrame](https://github.com/devframes/devframe) for a native DevTools experience.
* 🔌 **Standalone SPA:** a lightweight app distributed as static files, served by whichever integration you use.
